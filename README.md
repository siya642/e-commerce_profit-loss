# E-Commerce Sales Analysis | SQL & Power BI

## 📌 Project Overview

An e-commerce sales analysis project using **SQL and Power BI** to analyze **3,500 sales records** from 2022–2024 and generate meaningful business insights.

## 🎯 Objectives

* Analyze sales, profit, and quantity performance.
* Identify top-performing products and categories.
* Compare regional sales performance.
* Analyze sales trends over time.
* Build an interactive **Power BI dashboard** for data visualization and reporting.

## 🛠️ Tools & Technologies

**SQL | MySQL | Power BI | Data Analysis**

## 📊 Key Insights

* Product & category performance
* Regional sales analysis
* Revenue & profit analysis
* Quantity sold
* Monthly & yearly sales trends
* Top-performing products

## 📈 Dashboard

An interactive Power BI dashboard was created to visualize **Sales, Profit, Quantity, Product, Category, Region, and Time-based performance**.

## 💡 Outcome

This project demonstrates how **SQL can be used for data analysis and Power BI for interactive visualization**, transforming raw sales data into actionable business insights.
